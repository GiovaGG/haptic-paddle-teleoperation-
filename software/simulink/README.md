The final model screenshot is at [`../../assets/final-simulink-model.png`](../../assets/final-simulink-model.png), and [10 authentic Simulink screenshots are catalogued here](../../docs/simulink-screenshots.md). The architecture and MATLAB Function logic are documented in [`../../docs/control-algorithms.md`](../../docs/control-algorithms.md) and in `../matlab/`.

**Before uploading an `.slx`:** verify the solver/sample period (`0.02 s`), Arduino hardware package dependencies, actual pin mapping, startup calibration gating, motor sign, saturation and memory fit. Add the MATLAB/Simulink release used and a concise run guide.
