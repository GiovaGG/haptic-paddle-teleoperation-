# Ready-to-use portfolio description

**Haptic Paddle & Sensor-Based Robotic Teleoperation**  
*MATLAB/Simulink · Arduino Uno · Embedded Control · C/C++ · Prototyping*

Designed and integrated a low-cost, one-DOF haptic interface with a servo-actuated LEGO robotic arm for master–slave teleoperation. Rebuilt a LabVIEW control architecture in Simulink and deployed embedded control to Arduino Uno. Developed angular calibration, a proportional velocity observer, filtered servo position mapping and proximity-dependent resistive feedback using an HC-SR04 ultrasonic sensor. Improved feedback directionality through a hysteresis-based obstacle-side latch, addressing ultrasonic noise and microcontroller memory constraints.
